# SETUAI Learning Platform

An interactive AI literacy platform based on the SetuAI textbook.

## Start here

Our first milestone is one complete learning experience: open a lesson, complete a short quiz, receive useful feedback, and return to saved progress.

**First team assignment:** [Team kickoff](docs/TEAM_KICKOFF.md).
**Work queue:** [GitHub issues](https://github.com/Earthiscool/SETUAI/issues).
**How to contribute:** [Contribution guide](CONTRIBUTING.md).

No frontend, backend, or UI/UX leads have been appointed. All starting issues are unassigned. Members volunteer for a task; Agastya confirms one accountable owner and a reviewer. Temporary task ownership does not appoint someone as a team lead.

## Current state

This repository contains planning and collaboration documents only. No framework, database, hosting service, or application has been selected or implemented. Installation and run commands will be added when the starter application exists.

## First milestone

- One approved textbook lesson with clear learning objectives.
- A mobile and desktop lesson experience.
- A short quiz with answer explanations.
- Progress that persists across a return visit, under an explicitly agreed identity/storage approach.
- A working demonstration and checks against the agreed acceptance criteria.

Additional chapters, AI tutors, certificates, payments, and gamification are outside this first milestone.

## Working agreement

Use issues to record tasks and decisions. Use small task branches and reviewed pull requests for code. Keep the default branch working. Chat is for quick coordination; copy decisions into the relevant issue.

This repository is currently public. Only add textbook material Agastya has approved for public inclusion. Do not post passwords, API keys, personal contact details, or learner records.
